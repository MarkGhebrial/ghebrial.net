# Tangent

Tangent is a T-pull bullpup springer. Unlike other blasters with the same external layout, Tangent's layout maximizes the draw length to blaster length ratio.

Like the Charamile Designs Skewer, Tangent's priming handle is connected to a rod
that runs coaxially inside the plunger tube. Unlike the Skewer, the end of the rod
is not connected to a ram. Instead it's connected to a catch mechanism
